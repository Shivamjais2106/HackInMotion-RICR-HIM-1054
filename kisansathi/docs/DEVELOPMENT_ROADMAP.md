# 🚀 KisanSathi - Strategic Engineering Roadmap (`DEVELOPMENT_ROADMAP.md`)

This document details the multi-phase engineering roadmap and technological evolution of **KisanSathi**.

---

## 🎯 Milestone 1: Smart Farm Decision Support Engine (Version 5.0 - Completed)
- [x] **Persistent Farm Profile Entity**: MongoDB storage for land area, soil category, crops, and pump capacity.
- [x] **Hargreaves Evapotranspiration ($ET_0$) Irrigation Calculator**: Mathematical radiation model calculating water requirement in Liters/Acre and motor pump run hours.
- [x] **Pest & Climate Microclimate Threat Matrix**: Atmospheric hazard diagnostics for Fungal Blight, Frost, and Aphids.
- [x] **Live APMC Mandi Price Intelligence**: 7-day commodity trend charts (Recharts) & trade advisories.
- [x] **Unified Farmer Command Center**: Real-time React 18 dashboard.

---

## 🛰️ Milestone 2: IoT Soil Sensor & Satellite Vegetation Analytics (Version 6.0 - Q4 2026)
- [ ] **ESP32 / LoRaWAN Soil Sensor Integration**: Direct real-time soil moisture and N-P-K sensor ingestion via WebSockets.
- [ ] **Sentinel-2 Satellite NDVI Tracking**: Multi-spectral satellite index integration for remote crop vigor analytics.
- [ ] **Offline PWA Engine**: IndexedDB & Service Worker caching for remote farm usage without active internet.

---

## 🤖 Milestone 3: Multilingual Voice & Autonomous Pump Actuation (Version 7.0 - Q1 2027)
- [ ] **Native Voice Assistant**: Real-time voice interaction in Hindi, Punjabi, Marathi, Telugu, and Tamil.
- [ ] **Autonomous Solenoid Irrigation Valves**: Microcontroller integration to open/close drip valves automatically based on daily $ET_0$ calculations.
